# LunaScope 项目规范

通用规则沿用团队《iOS App 开发规范》。[产品介绍](../README.md) · [实现与验证](development.md) · [文档索引](README.md)

## 工程约定

- `App/` 装配工作区，`LunaScope/Features/` 按特性组织业务，`LunaScope/Infrastructure/` 提供跨特性支持，`LunaScope/Resources/` 保存资源，`Config/` 保存工程配置。
- 底部页签从左至右为相机连接、拍摄、相册、设置。首次打开进入相机连接；连接成功后自动进入拍摄页，随后恢复当前窗口的页签。
- App 使用 Swift 5 语言模式，主工程的部署目标为 iOS 27。
- App 全局使用深色模式：根部统一 `preferredColorScheme(.dark)`，Info.plist 以 `UIUserInterfaceStyle` 固定 Dark，页面不再单独声明配色。
- 英语为开发语言，支持英语和简体中文。用户文案统一放在 `LunaScope/Resources/<lang>.lproj/Localizable.strings`（一种语言一个文件；Widget 通过符号链接共用），用途说明放在同目录的 `InfoPlist.strings`。关键控制使用稳定的无障碍标识。

## 拍摄约束

- 拍摄设置先接受界面选择，再按顺序异步下发。相机回读用于补充未选择的值、确认写入和判断设备状态。同步失败时保留选择，用户可重试或采用相机设置。参数预设支持多组，同一预设以 ID 删除，云台记忆位置保持独立。
- 变焦以官方焦段和当前拍摄规格为准，同时受相机会话的可写范围限制。界面按用户选择高亮焦段，尚未操作时显示相机读数。
- 云台只记忆最近保存的一处角度及当时的翻转状态，必须由同一相机空闲时读取和恢复。恢复成功以相机回读为准。早期记录只有角度时按原有数据恢复。
- 相机相册从底部页签进入，浏览期间独占控制会话。浏览时保留实况和拍摄状态，关闭时释放锁。内置与 SD 卡按相机回读切换，列表和缩略图只从当前相机地址读取。拍照不自动写入手机相册，由用户在相册中勾选后保存到系统 LunaScope 相册。JPG、DNG 与 MP4 流式下载并校验魔数后按类型导入，其他文件不可选。只请求添加照片权限，拒绝时给系统设置入口。
- 云台睡眠按官方做法用拍摄视图状态（cmd 118 {1:5}）唤醒并以状态回读确认。拍摄视图内收到休眠通知后自动唤醒，忙碌或浏览相册时暂缓。控制台也提供手动唤醒。
- 意外断线在约 45 秒预算内沿上次路由自动重连（BLE 引导唤醒相机 Wi-Fi），保留已选相机与记忆；超预算给出重试入口，回到前台自动再试。用户主动断开不重连。
- 相机发现、配对和断开集中在「相机连接」页。实时活动展示连接与录像 / 连拍等已知状态；空闲后台过期后提示打开 App 核实。活动不包含相机名称或配对信息。点按活动仅激活 App。
- 相机拍摄、写卡和全景合成期间暂缓预览故障判断。实际传输断开后沿原路由重连。
- 全屏预览保留相机画面比例。界面旋转或切换全屏时沿用同一视频层。实况照片限标准照片，状态以相机回报为准。

## 回归

每次改动验证模拟器工程。连接、姿态回读、机身快门、相册及写卡行为按 [开发说明](development.md) 的真机清单核对。
