# 相机型号配置（CameraProfile）说明

资源目录：`LunaScope/Resources/CameraProfiles/CameraProfile-*.json`  
解析代码：`ConsoleCameraProfile.swift`  
视频 ID → 分辨率表：`LunaSchemaTables.swift`（`LunaVideoResolution`）

每台机一份 JSON，描述**该型号在控制台里允许的模式、格式和参数**。连上设备后按 `deviceModels` 匹配；字段里的数字大多是相机协议枚举（raw value），发送时原样写入，不靠口头名字翻译。

当前已打包：`luna-pro`、`luna-ultra`。两机视频规格 ID 列表相同，差异主要在变焦上限与变焦覆盖规则。

---

## 1. 顶层字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `schemaVersion` | `Int` | 配置格式版本，加载时必须为 `1` |
| `id` | `String` | 稳定内部 ID，如 `luna-pro` |
| `displayName` | `String` | UI 显示名 |
| `deviceModels` | `[String]` | 与相机回报型号做匹配（大小写不敏感） |
| `bluetoothPrefixes` | `[String]` | 蓝牙扫描名前缀 |
| `modes` | `Object` | 各拍摄模式能力，见 §2 |
| `photoFormats` | `[Object]` | 照片规格列表，见 §3 |
| `rawPhoto` | `Bool` | 是否支持 JPG+RAW |
| `livePhotoFormatIDs` | `[UInt64]` | 允许开启实况照片的照片规格 ID |
| `exposure` | `Object` | ISO / 快门档位，见 §4 |
| `whiteBalance` | `Object` | 色温范围与步进（开尔文） |
| `imageControls` | 数组 | 各拍摄模式的画面项、可选值和恢复默认值，见 §5.4 |
| `colors` | `[UInt64]` | 默认可选色彩模式，见 §5 |
| `colorOverrides` | `{ "格式ID": [色彩ID...] }` | 特定视频格式强制/收窄色彩 |
| `zoomStops` | `[Double]` | UI 变焦档位标记（不等于协议命令） |
| `gimbalModes` | `[UInt64]` | 云台模式协议值，见 §5 |
| `detachableScreen` | `Bool` | 是否具备可拆屏幕相关能力 |

可选扩展（代码已支持，当前 JSON 未使用）：

| 字段 | 含义 |
|---|---|
| `videoDefinitions` | `{ "格式ID": { width, height, framesPerSecond } }`，覆盖/补充全局视频表 |

## 2. `modes`：拍摄模式

Key 对应 `ConsoleCaptureMode` / `LunaShootingMode`：

| JSON key | 拍摄模式 |
|---|---|
| `video` | 普通视频 |
| `pureVideo` | 纯净视频 |
| `slowMotion` | 慢动作 |
| `timelapse` | 延时 |
| `timeShift` | 时间推移 |
| `photo` | 拍照 |
| `pano` | 云台全景 |

某个 key **出现**即表示该模式可用（即使对象为空，如 `pano: {}`）。

每个模式对象字段：

| 字段 | 含义 |
|---|---|
| `tracking` | 是否支持跟拍；缺省视为不支持 |
| `videoFormats` | 该模式可选视频规格 ID 列表（拍照模式不需要） |
| `zoom` | 默认变焦规则；`null` 或不写 = 该模式不变焦 |
| `zoomOverrides` | 按格式覆盖默认变焦 |

### 2.1 变焦规则 `zoom` / `zoomOverrides[].rule`

| 字段 | 含义 |
|---|---|
| `maximum` | 连续变焦上限（如 Pro `4`、Ultra `15`） |
| `fixedStops` | 仅允许这些倍率档（如 `[1, 3]`） |
| `recordingLensStarts` | 录制镜头起始相关档位（Ultra 部分 8K 等格式） |
| `null`（仅 override） | 该批格式**禁止**变焦 |

`zoomOverrides` 项：

```json
{
  "formatIDs": [210, 211, 154],
  "rule": { "maximum": 3 }
}
```

匹配顺序：当前格式落在某条 `formatIDs` 中 → 用该条 `rule`；否则用模式默认 `zoom`。

### 2.2 Pro / Ultra 变焦差异（摘要）

| 场景 | Luna Pro | Luna Ultra |
|---|---|---|
| 普通/纯净/拍照默认 | `maximum: 4` | `maximum: 15` |
| 8K 与部分竖拍 4K 等 | `maximum: 3` | `maximum: 6` + `recordingLensStarts: [1, 3]` |
| 慢动作等高帧格式 | `rule: null`（禁变焦） | `fixedStops: [1, 3]` |
| 延时 / 时间推移 | `zoom: null` | `fixedStops: [1, 3]` |
| `zoomStops` UI 标记 | `[1, 2, 4]` | `[1, 2, 3, 6, 12, 15]` |

## 3. 照片规格 `photoFormats`

每项同时带协议 ID 与可读尺寸（照片项少，故展开书写）：

| 字段 | 含义 |
|---|---|
| `id` | 协议 `PhotoSize`（photography option 40） |
| `ratio` | 展示用比例文案 |
| `ratioCode` | 协议比例字段；`0` 表示 16:9 时请求里可省略该字段 |
| `quality` | `standard` / `ultra` |
| `width` / `height` | 像素 |

### 3.1 比例码 `ratioCode`

| 值 | 比例 |
|---:|---|
| `0` | 16:9 |
| `1` | 1:1 |
| `2` | 9:16 |
| `4` | 4:3 |
| `6` | 3:4 |

## 4. 曝光与白平衡

### 4.1 `exposure`

| 字段 | 含义 |
|---|---|
| `iso` | 固定 ISO。官方刻度从 100 到 6400，3200 后直接是 6400，没有 4000 和 5000 |
| `isoMax` | 自动 ISO 上限档（界面如 400Max）；必须是 `iso` 的子集 |
| `shutterDenominators` | 快门分母，可带小数。`8000` 是 1/8000 秒，`12.5` 是 1/12.5 秒。拍照和录像用同一条，界面另加自动 |
| `longPhotoShutters` | 一秒及更慢的快门，单位为秒。当前为 `1, 1.3, 1.6, 2, 2.5, 3, 3.2, 4, 5, 6, 7, 8, 9, 10, 13, 15, 20, 25, 30` |
| `slowVideoShutter` | 可选。指定格式的录像最慢改到 1/5 秒。当前两份配置都不使用 |

### 4.2 `whiteBalance`

| 字段 | 含义 |
|---|---|
| `minimum` / `maximum` | 色温范围（开尔文），当前 2000–10000 |
| `step` | 控制台刻度步进，当前 200 K。机身回读的其他有效色温也会显示 |

`0` 在代码里视为自动白平衡，始终允许。

### 4.3 普通与专业模式

A／M 对应当前拍摄模式的摄影选项 `100`（`IQ_3A_MODE`）。值为 `1` 时显示 **A（普通）**，为 `2` 时显示 **M（专业）**。点按后面板立即切换，机身写入与回读在后台排队。下发失败时恢复为相机回报的模式。

普通模式在面板内提供 EV 曝光补偿。专业模式提供快门、ISO、EV、白平衡、测光和对焦，快门和 ISO 可以各自选自动。机型 JSON 的 `imageControls` 再追加当前模式声明的画面项。

## 5. 小枚举：对焦 / 色彩 / 云台

这些数字对应 `LunaTransportProtocol` 里的枚举。

### 5.1 对焦 `imageControls` 中 `id: focus` → `LunaAFMode`

| ID | 含义 |
|---:|---|
| `1` | AF-S（单次对焦） |
| `3` | AF-C（连续对焦） |
| `6` | 展示对焦（Product Showcase） |

哪些模式列出展示对焦，由该项的 `modes` 决定。当前录像类模式是 `[1, 3, 6]`，照片和全景是 `[1, 3]`，默认都是 `3`。对焦入口位于 A／M 面板的专业页。全景模式的对焦入口位于拍摄配置栏。恢复预设时按当前模式的 `choices` 过滤。

### 5.4 `imageControls`

每一项声明 `id`、摄影 option、`modes`、`choices` 和 `default`。`default` 必须落在 `choices` 里，专业页的重置按钮写回这个值。`origin` 把线值显示成相对零点的有符号数。`labels` 把线值映射到本地化 key。`visibleWhen` 在另一项的当前值不在列表中时隐藏本项。

测光（`metering`，option `46`）在录像类模式和照片里可选：`0` 矩阵测光，`1` 人脸优先，默认 `1`。全景不列出。

当前录像类模式（`video`、`pureVideo`、`slowMotion`、`timelapse`、`timeShift`）除测光和对焦外还有：

| id | option | 可选值 | 默认 | 说明 |
|---|---:|---|---:|---|
| `breathingCompensation` | 101 | `0` 关，`1` 开 | `0` | 呼吸补偿 |
| `contrast` | 3 | `1`…`5`，原点 `3` | `3` | 界面显示 −2…+2。I-Log（色彩 `2`）时隐藏 |
| `saturation` | 4 | `1`…`5`，原点 `3` | `3` | 同上 |
| `sharpness` | 6 | `0` 低，`1` 中，`2` 高 | `1` | I-Log 时隐藏 |
| `color` | 35 | `1` 标准，`2` I-Log，`5` 杜比视界 | `1` | 只在专业页。格式覆盖仍看 `colorOverrides` |

照片列出测光和对焦。全景只有对焦。控制台按 `modes` 决定是否列出。

### 5.2 `colors` / `colorOverrides` → `LunaColorMode`

| ID | 含义 |
|---:|---|
| `1` | Standard |
| `2` | I-Log |
| `3` | Vivid（schema 有，官方 App 通常不提供） |
| `4` | HDR（同上） |
| `5` | Dolby Vision |

当前默认：`[1, 2, 5]`。  
`colorOverrides` 示例：`"27": [1]` → 视频规格 `27`（1080p240）仅允许 Standard。

### 5.3 `gimbalModes` → `LunaGimbalMode`

| ID | 含义（App UI 用语） |
|---:|---|
| `1` | FPV |
| `2` | 横滚锁定（Roll Lock） |
| `3` | 横滚 + 俯仰锁定 |
| `4` | 竖拍 FPV |
| `5` | Lock（schema，当前配置未列） |
| `6` | Stabilized Vertical（schema，当前配置未列） |

当前配置顺序：`[2, 3, 1, 4]`（影响 UI 展示顺序）。

## 7. 查阅与维护建议

1. **改能力以抓包/官方 App 为准**：新增视频 ID 前，确认 `LunaVideoResolution` 表里已有该 raw value（或提供 `videoDefinitions`）。
2. **不要用口头名当唯一键**：例如「4K30」可能对应多个 ID；配置与协议对齐用数字。
3. **小枚举可读对照以本文 §5 为准**；大列表以 §6 或 schema 表为准。
4. 加载失败（版本不对、型号冲突、JSON 坏）会在日志 `console.profile.load.*` 留下记录，该文件被跳过。

相关代码入口：

- 加载 / 匹配：`ConsoleCameraProfile.bundled` / `.matching(_:)`
- 模式内视频列表：`.video(for:)`
- 变焦规则：`.zoomRule(mode:format:)`
- 色彩收窄：`.colorChoices(for:)` / `.requiredColor(for:)`
